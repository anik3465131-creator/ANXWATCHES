# ANX WATCHES

Одностраничный сайт ANX WATCHES: HTML, CSS, JavaScript, GSAP через CDN.

## Локальный запуск

Открыть `index.html` в браузере или поднять локальный сервер:

```powershell
python -m http.server 8766
```

Затем открыть http://localhost:8766/

## Публикация

Сайт статический, публикуется через GitHub Pages из корня ветки `master`:
Settings → Pages → Source: Deploy from a branch → `master` / `(root)`.
